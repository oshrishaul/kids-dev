# מדענים קטנים 🔬 — חידון מדע אינטראקטיבי לילדים בני 5–6

חידון מדע בעברית, מותאם לילדים שעדיין לא קוראים: **כל שאלה וכל תשובה מוקראות בקול**,
לכל שאלה יש **אנימציה מקורית** שמדגימה את התופעה, והעיצוב גדול, צבעוני וידידותי לאצבע קטנה.

## איך מריצים

פשוט פותחים את `index.html` בדפדפן (כרום, ספארי, אדג'). זהו — אין התקנה, אין שרת, אין אינטרנט חובה.

**קובץ בודד לשליחה או לשימוש בלי אינטרנט:**

```bash
node tools/build-standalone.js   # יוצר dist/מדענים-קטנים.html
```

קובץ HTML אחד שמכיל הכול — אפשר לשלוח בוואטסאפ, לשמור בטלפון ולפתוח ישירות.

**כתובת ציבורית:** ה-workflow ב-`.github/workflows/pages.yml` מפרסם את החידון ל-GitHub Pages
בכל דחיפה ל-`main`. הפעלה חד-פעמית: Settings → Pages → Source: **GitHub Actions**.

להרצה דרך שרת מקומי (מומלץ אם רוצים להוסיף סרטונים מקומיים):

```bash
python3 -m http.server 8000
# ואז בדפדפן: http://localhost:8000
```

| נושא | מה לומדים |
|---|---|
| 🚀 חלל וכוכבים | השמש במרכז, יום ולילה, הירח, חלליות, אסטרונאוטים |
| 🫀 הגוף שלי | לב, ריאות, שיניים, עיניים, עצמות |
| 🦋 בעלי חיים | גלגול הפרפר, זימים, כנפיים, דבש, פינגווינים |
| 🌻 צמחים ופרחים | זרע שגדל, שמש ומים, שורשים, סתיו, האבקה |
| 🌈 מזג אוויר ומים | גשם, התאדות ומחזור המים, קשת, שלג, רוח |
| 🧪 חומרים וניסויים | המסת קרח, אדים, מגנטים, ציפה ושקיעה, ערבוב צבעים |

**חוויית המשתמש:**

- 🗣️ **קריינות בעברית** לשאלה, לכל תשובה בנפרד (כפתור רמקול קטן ליד כל תשובה),
  ולהסבר שאחרי התשובה. כפתור 🔊 גדול מקריא את השאלה וכל האפשרויות שוב.
- 🎵 **מוזיקת רקע עדינה + צלילי הצלחה ועידוד** — נוצרים בדפדפן (Web Audio), בלי קבצי שמע.
- 🔇 **שני כפתורי השתקה נפרדים** בראש המסך: אחד לקריינות, אחד למוזיקה והאפקטים.
  הבחירה נשמרת גם לפעם הבאה.
- 🎨 **30 אנימציות SVG מקוריות** — כוכבי לכת שמקיפים את השמש, לב שפועם, זחל שהופך לפרפר,
  שלולית שמתאדה, קרח שנמס, מגנט שמושך מתכות ועוד.
- 🎬 **תמיכה בסרטוני הדגמה** (יוטיוב או קובץ מקומי) — ראו "הוספת סרטונים" למטה.
- 🤗 **בלי תסכול**: תשובה שגויה נותנת ניסיון נוסף בעידוד, ואחרי שני ניסיונות
  התשובה הנכונה מוצגת בעדינות עם הסבר. אין טיימר ואין "הפסדת".
- ⭐ כוכב על כל תשובה נכונה מהפעם הראשונה, מסך סיום עם מדליה ומדבקה,
  והשיא לכל נושא נשמר במכשיר.
- ♿ נגישות: כפתורים גדולים (מעל 44px), ניווט מקלדת (1/2/3 לבחירת תשובה, Esc לסגירת סרטון),
  `aria-live` להודעות, וכיבוד `prefers-reduced-motion` למי שרגיש לתנועה.

## הוספת סרטונים 🎬

ברירת המחדל היא אנימציות מקוריות בלבד — הן נטענות מיד ולא תלויות באינטרנט.
כדי לצרף סרטון לשאלה מסוימת, עורכים את `js/videos.js`:

```js
const VIDEOS = {
  // 'מזהה-נושא:מספר-שאלה' (השאלות מתחילות מ-0)
  'weather:0': { title: 'מאיפה מגיע הגשם?', youtube: 'VIDEO_ID' },
  'plants:0':  { title: 'זרע שגדל',        src: 'assets/videos/seed.mp4' }
};
```

- `youtube` — המזהה שמופיע בכתובת אחרי `watch?v=`. מנוגן דרך `youtube-nocookie`.
- `src` — קובץ וידאו מקומי (למשל ב-`assets/videos/`). מומלץ: עובד גם בלי אינטרנט ובלי פרסומות.

כפתור "🎬 סרטון הדגמה" מופיע רק בשאלות שהוגדר להן סרטון. המוזיקה נעצרת אוטומטית
בזמן הצפייה וחוזרת בסגירה.

> מומלץ להורים: לבדוק כל סרטון לפני שמוסיפים אותו.

## הוספת שאלות

כל התוכן נמצא ב-`js/data.js`. שאלה היא אובייקט אחד:

```js
{
  scene: 'rainCloud',              // שם אנימציה מ-js/scenes.js
  q: 'מאיפה מגיע הגשם?',
  a: [
    { emoji: '☁️', text: 'מהעננים' },
    { emoji: '🚿', text: 'מברז ענק בשמיים' },
    { emoji: '🕳️', text: 'מתוך האדמה' }
  ],
  correct: 0,                      // אינדקס התשובה הנכונה
  explain: 'בתוך ענן יש המון טיפות מים קטנטנות…'
}
```

מומלץ 3 תשובות לשאלה — זה המספר שילדים בני 5–6 מצליחים לסרוק בנוחות.

## מבנה הפרויקט

```
index.html        שלד הדף: שלושה מסכים (בית / חידון / סיום) וחלון הסרטון
css/style.css     עיצוב + כל אנימציות ה-SVG (מחלקות a-*)
js/data.js        נושאים ושאלות  ← כאן עורכים תוכן
js/videos.js      הגדרת סרטונים (אופציונלי)
js/scenes.js      30 סצנות SVG מקוריות
js/audio.js       קריינות (Web Speech) + מוזיקה ואפקטים (Web Audio)
js/app.js         זרימת המסכים, ניקוד, משוב
```

### שתי מלכודות בקוד האנימציות (חשוב למי שעורך סצנות)

1. אלמנט עם מחלקת אנימציה **לא** יקבל גם `transform="translate(...)"` —
   ה-CSS דורס את התכונה. תמיד עוטפים: `<g class="a-x"><g transform="…">`.
2. בגלל `transform-box: fill-box` אין להשתמש ב-`rotate(זווית cx cy)` עם מרכז מפורש;
   במקום זה עוטפים ב-`<g transform="translate(cx cy) rotate(זווית)">`.

## דפדפנים ופתרון בעיות קריינות

הקריינות משתמשת ב-Web Speech API — כלומר במנוע ההקראה של המכשיר, לא בשירות חיצוני.
בעמוד הבית יש פאנל **"🎙️ הגדרות קול (להורים)"** לבחירת הקול ומהירות הדיבור, עם השמעת דוגמה.

### הקול נשמע מכני?

ברוב המכשירים מותקנים **כמה קולות עבריים באיכות שונה מאוד**, והדפדפן לא תמיד בוחר את הטוב.
החידון מדרג אותם אוטומטית (`voiceScore` ב-`js/audio.js`) ומעדיף קול עם
`Premium`/`Enhanced`/`Neural`, אחריו קולות רשת של גוגל, ומוריד בדירוג קולות `Compact`/`eSpeak`
שהם הישנים והמכניים ביותר. אפשר גם לבחור ידנית בפאנל, והבחירה נשמרת.

להתקנת קול איכותי יותר במכשיר:

| מערכת | איפה |
|---|---|
| iOS / macOS | הגדרות → נגישות → תוכן מדובר → קולות → עברית → **Carmit (Enhanced/Premium)** — הורדה חד-פעמית |
| אנדרואיד | הגדרות → ניהול כללי → טקסט לדיבור → מנוע Google → התקנת נתוני קול → עברית |
| Windows | הגדרות → שעה ושפה → דיבור → הוספת קולות → עברית |

שני כיוונונים שנעשו כדי להקטין את התחושה המכנית: **pitch נשאר 1.0** (הגבהת גובה הצליל על מנוע
פשוט נשמעת מתכתית), ולפני ההקראה הטקסט עובר ניקוי — אמוג'י, מקף עברי (־) ושלוש נקודות (…)
נקראים מוזר במנועי TTS ומוחלפים בהפסקות טבעיות.

החידון מזהה שלושה מצבים ומציג הודעה מתאימה:

| מצב | מה זה אומר | מה עושים |
|---|---|---|
| אין Web Speech בכלל | בדרך כלל כי הדף רץ בתוך iframe מוטמע (תצוגה מקדימה) | לפתוח את הדף בלשונית רגילה בדפדפן |
| אין קול עברי מותקן | הדפדפן תומך, אבל למכשיר חסר קול עברי | אנדרואיד: הגדרות → ניהול כללי → טקסט לדיבור → הורדת עברית. אייפון: הגדרות → נגישות → תוכן מדובר → קולות → עברית |
| הכול תקין | — | אין הודעה |

בכל מקרה החידון ממשיך לעבוד: הטקסט גדול, כל תשובה מלווה באמוג'י, ויש אנימציה לכל שאלה.

> הערה: דפדפנים חוסמים השמעת קול לפני מגע ראשון של המשתמש. הקריינות מתחילה
> אחרי הלחיצה הראשונה במסך — זו התנהגות מכוונת של הדפדפן, לא תקלה.
